# MODELZON — 3D Fashion Design Arena

تطبيق تصميم أزياء ثلاثي الأبعاد (ويب + أندرويد عبر Capacitor) — منصة Lovable / TanStack Start.

## ⚠️ اقرأ أولاً — بنية المستودع

| المسار | ما هو |
|---|---|
| `src/` + `public/` + باقي جذر المستودع | **التطبيق الحقيقي المحدَّث** (Batch 2) — هذا ما يجب تشغيله واستيراده |
| `MODELZON.1-main.zip` | نسخة أرشيفية للكود الأصلي قبل التعديلات (للاحتياط فقط — لا تُفتح ولا تُستخدم) |
| `www/index.html` | صفحة تحميل فارغة **لتطبيق الأندرويد فقط** (Capacitor shell). ليست التطبيق! أي معاينة ثابتة لهذا الملف ستظهر HTML بلا CSS — طبيعي ومقصود |

> **عند الاستيراد إلى Lovable:** استورد مستودع GitHub كاملاً (جذر المستودع)، ولا تفتح ملف `www/index.html` مباشرة، ولا تفك ضغط الـzip الداخلي.

## التشغيل محلياً

```bash
npm install
cp .env.example .env   # ثم ضع بيانات Supabase الحقيقية
npm run dev
```

بناء الإنتاج: `npm run build` — أندرويد: `npx cap sync` ثم فتح المشروع في Android Studio (التطبيق الأصلي يحمّل رابط النشر المباشر من `capacitor.config.ts`).

## متغيرات البيئة المطلوبة

- `VITE_SUPABASE_URL` + `VITE_SUPABASE_PUBLISHABLE_KEY` (الواجهة)
- `SUPABASE_SERVICE_ROLE_KEY` (دوال السيرفر: XP، التحكيم الآلي، الدردشة)
- مفاتيح Stripe / RevenueCat اختيارية (الاشتراكات)

## ملخص Batch 2

1. الدخول يفتح الاستوديو مباشرة (بدون شاشة رفع فيديو تلقائية)
2. أداة نص حيّة بلا شبكة فرش — معاينة فورية وعناصر قابلة للسحب/التدوير
3. منع الحفظ/التصنيع مع رسائل عربية واضحة إن لم يوجد تصميم (بلا أي نداء API)
4. مكتبة ملابس داكنة بأيقونات مسطّحة — داخل الاستوديو فقط
5. دائرة معاينة حيّة لحجم أداة التنعيم + سلايدر
6. فرش متمايزة (قلم حاد / رصاص محبب / ماركر شفاف مادّي) وذاكرة إعدادات لكل فرشاة
7. دردشة مجتمع لحظية أسفل مواضيع الساحة (أسلوب واتساب)
8. تحكيم AI تلقائي عند نهاية الجولة (+500/+500/0/−350 XP) بدون بطاقة «قيّمني»
9. تحديات AI أصعب + مطابقة غرف حسب الرتبة
10. حذف قسم مفاتيح API من الإعدادات (البوابة المُدارة سليمة)
11. إصلاح تسرب النص الأحمر في زوايا الكم (قصّ UV)
12. دمج تبويب «تحرير» كاملاً في تبويب «طباعة» وحذفه
13. تنظيف الريلز: إزالة شريط الرفع المكرر وإصلاح تداخل الكابشن
14. زر صعود للأعلى، تراجع/إعادة لعناصر التصميم، حذف شارة $0، تصفير التمرير عند تبديل التبويب، نوافذ تأكيد قبل الحذف
