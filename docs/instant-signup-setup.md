# تسجيل دخول فوري بدون تحقق إيميل — إعداد مطلوب بلوحة Supabase

الكود الآن يدعم تسجيل فوري (بخطوتين: إيميل+كلمة مرور، بعدها اسم العرض،
وبعدها دخول مباشر للتطبيق) — بس **فيه إعداد واحد لازم تسويه بنفسك بلوحة
Supabase**، مو بالكود، عشان يشتغل فعلياً بدون أي تحقق:

1. روح Supabase Dashboard → مشروعك → **Authentication** → **Providers** → **Email**
2. عطّل خيار **"Confirm email"**
3. احفظ

بدون هذا الإعداد، `supabase.auth.signUp()` برجع حساب بدون جلسة (session)
فوراً، ويطلب من المستخدم يفتح بريده الإلكتروني يأكد التسجيل أول — هذا
سلوك Supabase نفسه على مستوى المشروع، مو شي أقدر أتحكم فيه من كود
`AuthGate.tsx` أو `auth.tsx`. الكود مبني يتعامل صح مع الحالتين (لو الإعداد
مفعّل يعرض رسالة "تفقد بريدك"، ولو معطّل يدخل المستخدم على طول) — بس
النتيجة اللي تبيها (دخول فوري بدون أي تحقق) تحتاج تعطيل الخيار فوق.
